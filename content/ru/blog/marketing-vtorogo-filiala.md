Первый филиал работает, клиенты есть, бизнес растёт — естественный следующий шаг: второй филиал. Многие предприниматели думают: «первый сработал — сработает и второй». Но второй филиал часто растёт медленнее ожидаемого: в новом районе вас никто не знает, репутация первого не переходит автоматически, а реклама смешивается между двумя точками. Разберём, как организовать маркетинг второго филиала.

## Данные маркетинга при выборе места

Место для второго филиала часто выбирают по цене аренды или «здание знакомого». А данные маркетинга — гораздо лучший советчик:

- **Адреса в CRM**: из каких районов приходят ваши клиенты? Район, откуда много клиентов едут издалека, — готовый спрос.
- **Статистика рекламы**: из каких районов в Meta много заявок, но мало продаж? Возможно, им далеко.
- **Адреса доставки**: куда чаще уходят онлайн-заказы?
- **Запросы на картах**: в статистике карточки Google и Яндекса видно, откуда люди строят маршрут.
- **Конкуренция**: есть ли в выбранном районе похожий бизнес и как он работает.

О рекламе по регионам — [реклама в регионах](/ru/blog/reklama-v-regionakh-uzbekistana/).

## До открытия: 4–8 недель

Второй филиал успешен не тогда, когда ждут «открылись — клиенты придут», а когда маркетинг начинается до открытия:

| Срок | Что делать |
|---|---|
| За 8 недель | Создать карточку на картах (с датой открытия), утвердить место |
| За 6 недель | Реклама по району: «Скоро в Юнусабаде» + лист ожидания |
| За 4 недели | Видео ремонта и подготовки, местные блогеры |
| За 2 недели | Предложение к открытию для листа ожидания |
| Открытие | Мероприятие в день открытия, реклама по району, старт сбора отзывов |

Подробный план для открытия нового бизнеса — [маркетинг до открытия](/ru/blog/marketing-do-otkrytiya/).

## Использовать репутацию первого филиала

Главное преимущество второго филиала — он не начинает с нуля. У первого есть отзывы, клиенты, контент. Используйте:

- **сообщение существующим клиентам**: новый филиал может быть им ближе;
- **«5 лет в нашем филиале на Чиланзаре»** — показывать опыт в рекламе;
- **единый стандарт сервиса**: клиент ждёт во втором филиале того же качества;
- **отзывы**: но карточка каждого филиала на картах должна собирать свои отзывы.

## Карточки на картах: отдельно для каждого филиала

Самая частая ошибка — оба филиала в одной карточке или у второго карточки нет вообще. Для каждого филиала:

- отдельная карточка в Google и Яндекс Картах;
- свой адрес, телефон, часы работы, фото;
- свои отзывы — после открытия просите отзыв у первых клиентов;
- карточки не должны противоречить друг другу.

Подробнее — [как добавить бизнес на карты](/ru/blog/kak-dobavit-biznes-na-karty/). Отзывы — [репутация и отзывы](/ru/blog/reputatsiya-i-otzyvy/).

## Реклама: один кабинет, раздельный результат

Оба филиала могут быть в одном рекламном кабинете, но результаты должны быть видны отдельно:

- **отдельные кампании** или группы объявлений на каждый филиал, с районом вокруг филиала;
- **название и адрес филиала в креативе**: «Юнусабад, улица ...» — человек сразу понимает, куда идти;
- **отдельная форма или UTM**: в CRM видно, для какого филиала заявка — [UTM-метки](/ru/blog/utm-metki/);
- **маршрутизация заявок**: заявка попадает менеджеру нужного филиала.

## Бюджет: новому филиалу больше

Типичная ошибка — делить бюджет между филиалами поровну. Новому филиалу в первые месяцы нужно больше узнаваемости и потока клиентов. Условный подход:

- первые 2–3 месяца: новому филиалу — большая часть общего бюджета;
- дальше: по результату — по цене клиента и загрузке каждого филиала.

Расчёт бюджета — [как планировать маркетинговый бюджет](/ru/blog/kak-planirovat-marketingovyy-byudzhet/).

## Учёт результата по филиалам

Каждый месяц по каждому филиалу:

| Показатель | Филиал 1 | Филиал 2 |
|---|---|---|
| Расход на рекламу | | |
| Заявки | | |
| Новые клиенты | | |
| Цена клиента | | |
| Выручка | | |
| Число отзывов и рейтинг | | |

В новом филиале в первые месяцы цена клиента выше — это нормально. Важна динамика: она должна снижаться каждый месяц.

## Частые ошибки

- Выбирать место только по цене аренды.
- Начинать рекламу в день открытия — поздно.
- Одна карточка на картах на два филиала.
- Не указывать в рекламе, какой это филиал.
- Не разделять результаты по филиалам.
- Не контролировать стандарт сервиса в новом филиале — первые негативные отзывы бьют по всему бренду.

## Вопросы и ответы

### Нужен ли второму филиалу отдельный Instagram?

Чаще нет: одна страница бренда, филиалы — в highlights и постах. Если филиалы сильно отличаются или находятся в другом городе — можно подумать об отдельной странице.

### За сколько окупается новый филиал?

Зависит от ниши и места. С точки зрения маркетинга первые 2–3 месяца — период узнаваемости, потом цена клиента должна приблизиться к первому филиалу.

### Не перетекут ли клиенты первого филиала во второй, оставив первый пустым?

Такой риск есть, если филиалы слишком близко. При выборе места проверьте адреса клиентов в CRM — пусть филиалы обслуживают разную аудиторию.

### Если франшиза, кто отвечает за маркетинг?

Зависит от договора. Обычно бренд-маркетинг — в центре, локальная реклама — на филиале. Пропишите правила заранее.

## Вывод

Второй филиал — новый рынок, но не с нуля. Выбирайте место по данным, начинайте маркетинг за 4–8 недель до открытия, дайте каждому филиалу отдельную карточку и группу объявлений и считайте результат по филиалам.
